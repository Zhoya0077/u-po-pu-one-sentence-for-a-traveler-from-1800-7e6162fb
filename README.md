One sentence, at most 200 characters, that explains the modern internet to a time traveler who has just stepped out of the year 1800 — built only from things they already know: a road, a post office, a library, a letter, a book, a spoken word, a blink. No word in it was coined after their time.

## Run it

```sh
node main.ts
```

The program writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
